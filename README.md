# JobConnect Website

A job portal website that helps job seekers explore job opportunities and connect with companies.

## Features

- Home page
- Browse available jobs
- Job details page
- Company listings
- User login and registration
- About and contact pages

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

```text
JobConnect Website/
├── index.html
├── about.html
├── jobs.html
├── jobdetails.html
├── companies.html
├── login.html
├── register.html
├── contact.html
└── css/
    └── style.css
```

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
